# 🛒 Retail Store Analysis using SQL
📌 Project Overview

This project focuses on analyzing a retail store dataset using SQL to generate business insights. The dataset includes information about customers, orders, products, payments, sellers, and reviews. The goal of this project is to understand sales performance, customer behavior, and delivery trends using SQL queries.

# 🎯 Objective

The main objective of this project is to use SQL to answer business questions and extract meaningful insights from retail data. This helps businesses understand product demand, seller performance, and customer activity.

# 🛠️ Tools & Technologies

SQL

MySQL

Relational Database Concepts

# 🔄 Project Tasks
✅ Data Understanding

Worked with multiple related tables such as customers, orders, products, payments, reviews, and sellers.

Explored table relationships using primary and foreign keys.

✅ Data Analysis using SQL

Used joins to combine data from multiple tables.

Applied aggregations to calculate sales and order metrics.

Analyzed delivery performance and order trends.

Identified top-performing products and sellers.

# 💡 Key Insights

Identified categories with highest sales.

Found sellers with strong performance.

Analyzed customer ordering behavior.

Studied order delivery patterns.
